# ZeroDistance 体积审查

日期：2026-10-21，Windows x64。审查对象为 0.2.1 正式成品，以及优化后的 0.2.2。所有 MB 均按 1,000,000 字节计算；解压占用为普通文件的逻辑大小之和，不包含游戏、Java、用户配置或文件系统分配开销。

结论：本次可以做小幅且不损失效果的优化，但不能通过删减业务代码把 Electron 版本变成几十 MB 的完整独立应用。按用户“重写若很耗时就取消”的要求，保留现项目，不新建项目重写。

## 实测对比

| 项目 | 0.2.1 | 0.2.2 | 减少 |
| --- | ---: | ---: | ---: |
| 安装程序 | 98,093,874 B（98.09 MB） | 98,052,744 B（98.05 MB） | 41,130 B（约 0.04 MB） |
| 完整 ZIP | 140,334,023 B（140.33 MB） | 133,515,550 B（133.52 MB） | 6,818,473 B（6.82 MB，约 4.86%） |
| 解压后的完整程序 | 320,661,058 B（320.66 MB） | 316,925,156 B（316.93 MB） | 3,735,902 B（3.74 MB，约 1.17%） |
| 应用 ASAR | 10,867,188 B（10.87 MB） | 7,131,016 B（7.13 MB） | 3,736,172 B（约 34.38%） |

应用 ASAR 的 34% 降幅不等于完整软件减少 34%。安装程序已经采用更适合可执行文件的压缩，进一步去重只让它减少约 41 KB；ZIP 的主要收益来自提高 Deflate 压缩强度。

0.2.1 的完整程序构成：

| 构成 | 大小 | 说明 |
| --- | ---: | --- |
| Electron 运行文件 | 288.19 MB | 其中主 EXE 为 246.07 MB；还包括 Chromium 资源、国际化数据、图形和媒体组件。 |
| 许可和说明材料 | 20.55 MB | 主要为 Electron 随附的 Chromium 第三方许可 HTML，完整保留。 |
| 应用、依赖和素材 | 11.92 MB | ASAR 与解包的原生辅助文件；优化后为 8.19 MB。 |

运行文件与许可约占原程序的 96%。Electron 官方说明它会嵌入 Chromium 与 Node.js，因此更换业务代码语言而仍分发相同运行时，不会消除这部分体积。参考：[Electron 架构说明](https://www.electronjs.org/docs/latest/tutorial/tutorial-prerequisites)。

## 代码和依赖检查

- 已检查构建配置、产物清单、依赖引用和大文件。没有把开发用的完整 `node_modules`、RAW 照片、游戏、Java、测试缓存或历史发行版放入安装包。
- 主进程、网页与工作线程均已启用代码压缩。运行依赖只有实际使用的 ZIP、TOML、WebSocket、HTTP 与原生调用组件；Windows 包使用对应的 Koffi x64 文件。
- 四张默认照片总计 717,084 B，已经是 WebP。进一步压图对整体收益很小，本次保持原文件与散列。
- 找到投影注册表重复：原始 JSON 为 2,093,090 B，分别进入主进程与工作线程编译结果，合计重复约 3.76 MB。
- 现将注册表压成一份 23,483 B 的 Brotli 文件，由两个进程读取同一份磁盘文件。没有删版本、方块属性或旧格式映射；源码 JSON、提取脚本、来源和许可均保留。构建和打包时核对解压后的全部字节。
- ZIP 从 zlib level 6 改为 7-Zip 的标准 Deflate，三轮压缩；避免原构建工具十五轮压缩的较长耗时。仍是完整解压直接运行的 ZIP，使用方法 0 / 8，不采用需要额外解压工具的压缩方法。
- 保留图形软件回退、着色器和媒体组件，以维持 3D 皮肤与录像功能的兼容性。没有通过删除这些运行文件、降低照片清晰度或更换旧运行时来缩小数字。

## 重写评估

本次源码统计：348 个 TS / Vue / CSS 文件，约 54,202 行；其中主进程约 28,229 行，59 个文件直接引用 Electron，257 处主进程 IPC 注册。该数量用于估计适配面，不是逐行人工安全审计结论。

可降低分发体积的方案是依赖系统 WebView，例如 Tauri + Rust。网页 UI 和部分视觉资产有复用可能；Tauri 官方说明它使用系统 WebView，因此不需要随应用携带一份完整浏览器。参考：[Tauri 架构](https://v2.tauri.app/concept/architecture/)。

但当前后端使用 Node/Electron 的文件、网络、账号加密、进程、原生窗口、资源协议、工作线程和 IPC。迁移需要适配或改写这些部分，并重新验证 Microsoft 登录、下载修复、加载器、整合包、游戏进程、皮肤、窗口、联机和同意流程。简单保留 Node sidecar 可以复用部分逻辑，仍需处理上述 Electron 依赖，而且要继续分发对应运行组件，不能把空项目示例的体积当作完整启动器承诺。参考：[Tauri 外部程序](https://v2.tauri.app/develop/sidecar/)。

系统 WebView 的“小包”也有运行环境前提。Tauri 的 Windows 分发支持在线补装、系统既有运行时或嵌入离线 WebView2；官方列出的嵌入式离线安装器与固定运行时会额外增加明显体积。参考：[WebView2 安装方式](https://v2.tauri.app/distribute/windows-installer/#webview2-installation-options)。

因此本次不重写，也不承诺一次迁移便能完整保留现有行为。当前两项优化已经落地为 0.2.2，保留现有功能继续使用。

## 验证与复查

- 82 项原有核心回归、2 项完整注册表与状态校验、5 项启动检查、类型与许可检查通过。
- 打包后的 Electron 主进程返回全部注册表版本；真实工作线程读出 1.20.1、26.3 结构与旧数字 ID 格式，并把 26.3 结构转换为 Sponge 文件。原文件散列保持不变。
- 正式包的 5 组菜单／版本设置检查通过；构建后的 3D 皮肤 9 组动作与像素检查通过。
- 最终 ZIP 共 48 个普通文件，逐文件解压内容与 `win-unpacked` 的 SHA256 一致。ZIP 的首次声明检查、安装程序在独立 QA 目录的安装、启动、联网后端与卸载通过；正式用户账号、设置和同意记录不变。
- Minecraft 清单、Modrinth 模组和整合包、Java 检测及皮肤模组文件接口检查通过。

可重新执行：`npm run audit:size`、`npm run test:size`、`npm run test:size:desktop`。程序需先构建或打包；桌面脚本使用独立 QA 用户目录。新旧体积记录保存在 `docs/size-audit-0.2.1.json` 与 `docs/size-audit-0.2.2.json`。
