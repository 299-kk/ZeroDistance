# ZeroDistance 0.2.2 Preview

本次针对分发体积做两项优化：投影方块注册表改为一份无损压缩数据，避免主进程与工作线程重复打包；完整 ZIP 改用标准 Deflate 的三轮压缩。保留所有方块版本与属性、照片、3D 皮肤、录像和联机功能。

| 成品 | 0.2.1 | 0.2.2 |
| --- | ---: | ---: |
| 安装程序 | 98.09 MB | 98.05 MB |
| 完整 ZIP | 140.33 MB | 133.52 MB |
| 解压后占用 | 320.66 MB | 316.93 MB |
| 应用 ASAR | 10.87 MB | 7.13 MB |

整体收益有限：体积主要来自 Electron 运行组件。按用户要求评估后，本次不启动成本较高的重写。完整分析、运行框架替代方案与验证范围见 [体积审查](SIZE_AUDIT.md)。

82 项核心回归、2 项注册表检查、5 项启动测试、类型与许可检查通过。正式包通过投影线程读写和转换、菜单设置、ZIP 逐文件内容比对、首次声明，以及独立目录安装、启动与卸载检查。3D 皮肤 9 组动作检查通过。测试没有改动正式用户的数据。

文件：`ZeroDistance-0.2.2-Setup.exe`（98,052,744 B）、`ZeroDistance-0.2.2-windows-x64.zip`（133,515,550 B）和对应源码压缩包。校验值见 `SHA256SUMS.txt`。
