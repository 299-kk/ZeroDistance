# ZeroDistance 0.3.0-native.4 启动与外观验证

日期：2026 年 10 月 22 日。Windows x64 / .NET Framework 4.8 / 系统 WebView2。本次不新增游戏或联机功能。

## 用户可见变化

- 设置 → 外观新增“关闭启动动画”，默认不勾选。勾选后下次启动不创建动画辅助进程，界面准备好就直接显示；取消后恢复启动效果。它不改变应用或系统的减少动态效果设置。
- 默认主题 `transparent` 恢复 0.1.4“零距·青柠”的全部九个颜色值；其他主题键、配色和界面布局保持原样。已选择其他主题的配置继续生效。
- 优化页面加载与启动动画并行顺序，初始窗口透明度在首次显示前设为零，避免先显示黑框再隐藏。
- 修复设置页后台请求尚未结束时退出的集合修改异常：先取出并清空请求集合，再完成任务回调，避免同步回调修改正在枚举的字典。

青柠参考取自本地 0.1.4 已验证 ZIP 解压包的 `resources/app.asar`，该 ASAR 的 SHA-256 为 `1bad39908c8dd09b893b580548dfd9d5993f2fe2a14907018f7b554542d2c0de`。主色 `#c5f277`、背景 `#121713`、卡片 `#1b211c`、文字 `#edf1e9`、次要文字 `#8c998b`、边框 `#2b342b`、侧栏背景 `#101510`、侧栏文字 `#93a08f`、启动卡文字 `#ffffff`。

## 测试

生产构建、82 项核心测试、许可检查、2 组原生 DPAPI/图像服务检查通过。

`native-launcher/scripts/verify.cjs` 的 15 组检查通过：实际前台三秒使用声明及后端门禁、默认青柠和动画开关初值、更新历史、影视飓风轮播与署名、本地资源展开时 13px 字号及宽度稳定、游戏图标和大小、离线账号、3D 行走/待机/暂停、Slim 皮肤、真实文件路径、主题切换和保存、离线联机提示、实际 Modrinth 搜索、私有资源权限拒绝及正式配置保留、正常退出无未处理异常。

`native-launcher/scripts/verify-startup.cjs` 的 5 组检查通过：

1. 从上个发行版实际写入的旧地址 localStorage 迁移白名单偏好，排除无关键；授权图片仍可加载。
2. 初始 opacity 为零；主窗口 HWND 保持不变，显示后透明度恢复一并移除分层预热样式。
3. 模拟迁移标记中断，重试不覆盖新地址已写入的偏好。
4. 后续启动不重复迁移；系统减少动画时，通过仅限 QA 的参数实际绘制完整动画帧。
5. 从实际设置开关保存、正常关闭、重开：关闭动画时没有新动画信号或辅助进程，主界面正常显示；开关状态保留，取消后再次启动恢复动画。设置页后台请求仍在进行时正常退出，无未处理异常。

本轮原生集成检查通过内建 QA 焦点 API 验证前台计时，未使用外部鼠标或键盘注入。全部进程、账号和客户端样例均属于独立 `.qa` 目录；未启动游戏、未改变系统动画或正式配置。

## 启动耗时

`native-launcher/scripts/profile-startup.cjs` 从创建应用进程前开始计时，使用相同 QA 数据，普通浏览器参数且不开放调试端口。每组连续启动四次，第一遍预热，后三次取中位数；各轮都关闭自己启动的进程树。以下是已有缓存、已同意使用声明后的本机结果。

| 场景 | 首次启动反馈 | 主窗口开始显示 |
| --- | ---: | ---: |
| 修改前，系统减少动画 | 348 ms | 1,762 ms |
| 本次，系统减少动画 | 198 ms | 848 ms |
| 本次，强制完整动画，仅 QA | 409 ms | 847 ms |

完整动画后三次的主窗口开始显示为 847/833/860 ms；动画退场结束为 1,070/1,038/1,082 ms。主窗口淡入为 120 ms，不把开始显示等同于透明度已经达到一。

保留 `.local` 主页面地址时，即使使用空白诊断 HTML 仍出现约一秒解析前等待；换用保留的 `.test` 地址后该等待在本机消失。没有将底层延迟原因未经证实地归因于某一系统服务。内置页面使用 WebView2 的虚拟主机目录映射，已授权图片与插件继续使用独立通道。

首次升级需要访问一次旧地址来迁移本机 UI 偏好，可能另等约一秒；迁移标记落盘后跳过。不包括首次安装依赖、首次创建浏览器缓存、阅读声明或大量游戏扫描。调试连接本身会改变启动时间，因此功能集成测试中的调试模式耗时不用于性能结论；也不承诺其他机器一定在一秒内完成。

复测证据：`.qa/native-launcher/1ac93f1e-c675-46e7-af2c-42a497349371`、`.qa/startup-regression/a7dedbea-043d-4a23-9291-1db5293d944a/RESULT.json`、`.qa/startup-speed/6013b51f-a467-4fd2-a4b3-47866512706d/final.json` 与 `final-full.json`。这些本机测试数据不进入发行包；测试脚本随对应源码交付。
