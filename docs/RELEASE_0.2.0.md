# ZeroDistance 0.2.0 Preview

本次更新重新整理游戏库、离线账号与联机入口，同时保留上游版权和第三方许可。

| 项目 | 本次变化 |
| --- | --- |
| 大小与版本列表 | 启动台和游戏库显示实例目录占用；下载版本按大版本折叠，显示客户端、当前系统依赖与资源的下载估算。资源文件选择窗口突出显示具体文件大小。 |
| 启动状态 | 按进程事件显示正在运行的版本数与进程数，同一版本多开单独计数；重新打开启动器会恢复存活进程的状态。 |
| 离线皮肤 | 离线账号可保存 64×64 PNG，选择经典或纤细模型；可为所选游戏查找皮肤模组并同步本地配置。 |
| MOD 前置 | 默认以右下角后台任务显示，可展开或最小化，切换页面不会中断；检查完成后由用户确认安装。 |
| 离线联机 | 进入零距联机时说明主机验证设置，支持“不再提示”；下载推荐时带入当前版本与加载器，不会下载不兼容文件。 |
| 界面与主题 | 窄侧栏、分栏启动卡、游戏卡片；主题改为远山、白昼、落日、云间、星夜。旧主题键保留兼容。 |
| 应用背景 | 更名并说明用途，纯色与图片能透出到页面，与启动台照片轮播分别设置。 |
| 游戏目录 | 修复启动台文件夹按钮使用错误接口导致的“非法目录”。 |
| 更新记录 | 时间线、当前版本标记、版本标题与改动说明；实色面板保证文字可读。 |
| 使用声明 | 第一段按用户指定原文替换；声明版本更新为 2026-10-21.2，需要重新阅读并主动同意。 |

实例占用不重复计入共享 libraries、assets 与共享游戏目录。大型目录、读取失败或达到扫描上限时以“≥”标记部分结果。下载估算会复用已有缓存；Java、加载器与模组另外计算。整合包文件大小通常是清单或压缩包大小，不代表安装后的总占用。

离线皮肤在游戏内显示需要 [CustomSkinLoader](https://github.com/xfl03/MCCustomSkinLoader)，仅在本机可见。原版实例需要先安装支持的模组加载器。零距使用其 Legacy 本地皮肤接口，保留现有来源；修改已有配置前保存备份，配置损坏时停止修改。

[自定义局域网联机原项目](https://github.com/rikka0w0/LanServerProperties) 的兼容版本有限。当前筛选没有文件时，页面提供原作者推荐的 [LAN World Plug-n-Play](https://github.com/Satxm/mcwifipnp) 后续项目入口，保留同一版本和加载器条件。

## 验证记录

- 79 项核心与回归测试、5 项启动测试通过，TypeScript 检查与许可检查通过。
- 打包后的 EXE 通过 8 组新增流程验证：大小、运行数量、目录、离线皮肤、联机推荐、后台前置、版本分组和背景／更新记录。
- 4 张照片轮播的 8 项桌面检查、皮肤动作的 9 组像素变化检查通过。
- ZIP 解压后的首次使用流程通过；安装程序在独立测试目录完成安装、启动、资源接口检查和卸载。
- Minecraft 版本清单、模组、整合包、Java，以及推荐联机和皮肤模组的兼容文件接口返回正常。
- 测试同意记录仅写入工作区的独立测试目录；正式用户的同意记录、账号和设置保持不变。

本次未做真实 Minecraft 游戏内的离线皮肤显示和两台机器之间的联机验收。
