# ZeroDistance 产品说明

当前版本为 **0.3.2 Preview**，主要支持 Windows 10/11 x64。ZeroDistance 是独立的 Minecraft Java 版启动器，基于 KAMUCL 开发，并参考 Modrinth 与 PCL 的使用流程。项目不代表 Mojang、Microsoft 或参考项目的官方产品。

## 安装与首次使用

安装版提供目录选择和默认勾选的桌面快捷方式；不需要时可取消。ZIP 版必须完整解压后运行 `ZeroDistance.exe`，不能只复制主程序。运行需要 .NET Framework 4.8 和系统 WebView2 Runtime；游戏另需匹配版本的 Java，启动器可按设置检测或下载。

首次使用需阅读声明，保持窗口在前台至少三秒后主动同意。失去前台暂停计时，拒绝则退出。同意前不加载账号、游戏扫描或联机服务。声明更新后可能重新请求同意。

## 账号与皮肤

在“账号管理”添加 Microsoft 账号，通过微软官方设备授权页面完成登录。正版游戏授权仍由账号和 Minecraft 服务确认。离线账号只提供本地身份，不授予游戏或服务器访问权。

离线用户名为 3–16 位字母、数字或下划线。在“本地资源 → 皮肤”选择 64×64 PNG，并选择经典或纤细模型。3D 预览支持待机、行走、暂停、旋转和缩放。游戏内显示自定义离线皮肤需要兼容版本的 CustomSkinLoader；预览可见不代表其他玩家必然可见。

## 安装和导入游戏

“我的游戏”可安装原版及 Fabric、Forge、NeoForge、Quilt 等加载器，下载列表按版本系列折叠。也可导入 `.mrpack` 或兼容整合包 ZIP。整合包要求的游戏版本、加载器和依赖以清单为准。

默认游戏目录优先使用 `D:\ZeroDistance\.minecraft`，D 盘不可用时回退；已设置的目录会保留。软件会有限度地查找 MC、minecraft、.minecraft 和“我的世界”目录，也可手动登记。登记不等于搬动游戏。不同实例可使用独立目录，修改模组前先备份存档。

实例大小表示本地文件占用，不重复计入共享内容；显示“≥”说明扫描未能完整统计。资源页的下载大小表示文件或下载估算，不能直接当作安装完成后的磁盘占用。

## 资源与启动

“发现资源”按资源类型、Minecraft 版本和加载器筛选。Modrinth 可直接使用；其他服务可能要求用户自己的访问配置。模组、整合包、资源包、光影和数据包各有不同兼容要求。

模组前置检查在后台进行，可展开任务查看，切换页面不会中断；确认兼容后才安装。本地模组、资源包和光影页面支持导入文件。启动台会显示正在运行的游戏数量和版本，避免把“再次启动”误认为第一次没有启动。

## 好友联机

房主先启动游戏、进入世界并开放局域网，再把游戏显示的端口填入联机设置。双方应使用兼容的 Minecraft、加载器和模组配置。

| 方式 | 需要准备 | 结果 |
| --- | --- | --- |
| FRP | 对应服务账号、密钥、节点及隧道 | 好友使用映射地址加入 |
| VoxLink | 双方打开启动器、服务端可达 | 通过房间码取得加入地址 |
| 虚拟局域网 | 首次下载并校验相应官方工具，允许必要网络权限 | 使用虚拟网络地址与游戏端口加入 |

离线玩家加入前，房主需要允许相应身份验证方式。“我的游戏 → 版本更多菜单 → 局域网验证设置”可设置当前版本，下次启动生效。该选项不改变他人的服务器或独立服务端配置。网络地址、端口和游戏服务可能暴露给参与者，只邀请可信玩家。

## 外观与素材

默认主题是 0.1.4 的青柠，其余主题和个性化设置保留。“设置 → 外观 → 关闭启动动画”默认不勾选，下次启动生效；系统或应用的减少动态效果设置也会影响动画。

默认提供樱花山谷、雪山湖畔、月下营地、海岸落日四张 AI 生成的方块世界背景，随源码与发行包提供。用户仍可导入自己有权使用的图片，原有自定义图片保留。参见 [素材说明](VISUAL_ASSETS.md) 与 [AI 制作说明](AI_PROVENANCE.md)。

## 数据、更新和卸载

当前版本的数据目录继续使用 `%APPDATA%\ZeroDistance-Native`，名称保留是为了兼容已有账号、设置与声明记录。对外名称已统一为 ZeroDistance。旧 Electron 版使用另一个数据目录，不自动合并。

新版更新器优先 GitHub，失败后使用配置的镜像，验证发布签名、包体长度和 SHA-256，完整目录在正常退出后静默替换，下次打开生效。0.3.1 及更早版本先手动安装 0.3.2 一次；不支持任意无签名 ZIP，详见 [更新流程](NATIVE_UPDATES.md)。安装版卸载会清除本版本账号、设置、日志、缓存、临时文件、快捷方式及自身注册表；游戏目录和存档保留。旧版需要先覆盖安装新版，才能使用新的卸载逻辑。直接删除 ZIP 文件夹不会自动清理系统中的软件数据。

## 低占用模式

设置 → 行为与登录可点击“立即进入”，或开启“游戏启动后自动进入低占用模式”（默认关闭）。浏览器界面和非核心功能释放，已有联机服务继续运行；无活动核心时业务后端也休眠。通过原生小窗口或托盘恢复完整界面。下载、安装及未保存编辑会暂缓切换。正常界面未达到 100 MB，低占用的实际内存仍取决于联机组件，测量口径与结果见 [内存报告](MEMORY_2026-10-27.md)。

## 预览测试范围

已完成核心、界面、启动、原生服务和卸载等测试；具体结果以 [验证记录](TESTING.md) 为准。完整 Microsoft 授权、不同网络条件下的双机公网联机、高 DPI、多显示器仍需继续验证。软件仍含 Node.js 兼容业务引擎，不能把当前架构描述为全部后端已改写为 C#。
