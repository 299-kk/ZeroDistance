# ZeroDistance 玩家行为测试 · 2026-10-22

测试版本：0.3.0-native.2，以及修复后的 0.3.0-native.3 预览版。使用独立的 `.qa/player-behavior/` 配置、离线测试账号与客户端副本，不使用正式账号令牌。

## 当前状态

已完成一轮实际窗口操作，发现并修复一处资源导入入口问题；完整正版授权、双机公网联机与游戏内世界操作尚未验收，不能宣称全部功能通过。

用户协助添加首个离线账号 299 后，继续通过窗口按钮、表单、原生文件选择器、鼠标拖动和滚轮完成测试。实际操作覆盖目录登记、版本搜索与分组、安装配置取消、离线账号校验与切换、本地皮肤、资源包导入、社区光影下载、主题、更新历史、游戏启动及启动器正常退出。

Windows 操作工具曾数次返回 `GetCursorPos: 0x80070005`，桌面恢复活动后启动器页面可继续操作。Minecraft 窗口则持续出现工具报告的 `user input was detected` 或最小化状态，未完成世界创建与进入，不能据此判断游戏内功能是否正常。

修复后重新运行：82 项核心测试、2 项资源导入/多进程跟踪回归、2 组 C# 凭据及图像服务检查、许可检查均通过，原生生产构建成功。这些结果与下表的实际界面操作分别记录。

## 发现并修复的问题

资源包页的顶栏“导入”会打开整合包选择器，本地资源页没有文件导入按钮，容易误入整合包流程。

0.3.0-native.3 为模组、资源包、光影包新增本地文件导入按钮；原生选择器按资源种类筛选，沿用后端目录校验和同名文件保护；全局入口明确标为“导入整合包”。实测在资源包页选择测试 ZIP 后，列表从 0 项变为 1 项，显示 538 B 与“已导入 1 项到 26.3 / resourcepacks”，目标文件 SHA-256 与源文件相同。模组与光影按钮已构建，未分别重复其原生选择器完整流程。
