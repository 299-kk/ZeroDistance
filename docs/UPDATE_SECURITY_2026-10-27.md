# 更新链路安全检查与静默更新 · 2026-10-27

对象：发布前的 0.3.2 Preview。本轮检查时未上传 GitHub，未替换用户正式安装。检查覆盖启动器更新元数据、传输、签名、包体、缓存、更新助手及退出交接；不等同于对所有模组、联机服务、系统运行时的完整渗透测试。

## 结论与威胁边界

目前未发现只控制镜像站、网络响应或 GitHub 发布页面，就能绕过固定发布公钥安装任意程序的路径。元数据必须通过 RSA-SHA256 签名；下载包必须匹配签名中的固定版本、GitHub 仓库地址、字节数及 SHA-256。签名验证先于更新说明展示和 ZIP 解压。镜像可阻断更新、提供旧响应或造成网络失败，不能因此获得发布权限。该结论是本轮代码审查及故障测试的范围，不能保证不存在未知漏洞。

| 攻击条件 | 本版处理 |
| --- | --- |
| 镜像或 GitHub 返回伪造清单、改过的 ZIP | 签名或哈希失败，拒绝更新并保留当前程序 |
| 重放合法旧包 | 业务后端、启动交接和更新助手分别拒绝旧版/重复版本 |
| 重定向到 HTTP、带用户名密码的 URL 或循环跳转 | 拒绝降级和凭据 URL，跳转次数有上限；正常 HTTPS CDN 跳转保留 |
| 目录穿越、符号链接、设备名、Windows 路径别名或异常解压长度 | 拒绝路径或内容，在替换程序前失败 |
| 本地缓存的更新助手被替换 | 对照主程序嵌入的助手 SHA-256；只启动匹配指纹的助手 |
| 校验后有人尝试替换 ZIP | 同一个只读文件句柄用于校验与解压，期间拒绝写入/删除共享 |
| 发布签名私钥或发布者构建环境被攻破 | 仍可造成恶意的合法签名更新，属于剩余信任风险 |

## 本轮发现及修复

1. **生产依赖存在已知漏洞。** `undici 6.28.0` 更新为 `6.29.1`，`adm-zip 0.6.0` 更新为 `0.6.1`。更新网络响应在签名验证前就必须由 HTTP 客户端解析，网络解析漏洞不能仅靠包体签名防护；ZIP 工具也用于资源及构建流程。修补后 `npm audit --omit=dev` 为 0 项已知漏洞。完整开发依赖仍有 10 项（3 中等、7 高），不能宣称整个依赖树已无漏洞。
2. **恢复流程原先直接启动缓存目录里的助手。** 需要已有本地文件写权限，不能由单纯镜像控制直接触发。现在主程序嵌入助手指纹，临时助手必须匹配；受信任副本丢失时只能从匹配指纹的安装目录助手恢复，不信任下载元数据提供的助手路径。启动时短暂持有禁止写入和删除的助手句柄。恢复目标和数据目录还需匹配宿主固定目录。
3. **本机发布私钥继承了普通 Users 组可修改权限。** 已将私钥及其专用目录的 ACL 收紧到发布用户、SYSTEM 和管理员；签名前新增权限检查，拒绝过宽权限或链接。未显示、复制到报告或上传私钥。此措施不阻止以同一发布用户身份运行的恶意程序，正式发布仍建议使用离线或隔离签名环境，并保留受保护备份。
4. **更新边界补强。** 拒绝 HTTPS 降级、凭据重定向、重复版本、更新目录链接；使用独占创建的随机临时文件；限制记录读取和解压输出；原生助手拒绝设备名、尾点/尾空格路径别名和备用数据流，并限制动态库搜索范围。
5. **静默交接的长路径问题。** 深层测试目录触发 .NET 旧的 260 字符限制，导致实际包应用失败。本版显式启用现代路径处理与 longPathAware，再在同样深度复测通过；没有修改系统长路径注册表设置。

## 静默更新行为

新配置默认开启“设置 → 关于与更新 → 后台静默更新”；保留已有用户关闭自动更新的选择。发现可信新版本后后台下载，不弹安装向导或要求重新安装，也不强行退出正在使用的软件。用户正常退出后交给隐藏助手备份并替换文件，完成后保持退出，下次打开即为新版。下载未完成、尚有其他程序占用、退出异常或声明未同意时保留当前版本/记录；必要时下次启动恢复。已安装的 0.3.1 不包含这套更新器，仍需手动安装新版一次。

更新权限遵循当前用户，安装器和宿主请求 `asInvoker`，不主动申请管理员权限。用户主动以管理员身份启动的风险不能由签名机制消除。缓存 ACL、哈希和指纹也不能把已经完全控制当前用户账户的本地恶意程序隔离成可信程序。

npm 的生产依赖审计不覆盖系统 WebView2、.NET、附带 Node 二进制或未知漏洞，不能将“0 项已知 npm 漏洞”解释为整台电脑或全部运行时已无安全问题。系统运行时仍需保持更新。

## 测试与复测

- 更新助手 11 组：正常替换、备份、伪签名、损坏包、路径穿越、重复名、Windows 特殊路径、虚假解压长度、重放、链接、占用回滚和中断恢复（部分归在同一组）。
- 来源 7 组，下载 4 组（包含后台自动下载无更新弹窗）。
- 安全及静默交接 10 组：重定向、重放、目录链接、更新说明 HTML、助手指纹、ZIP 锁定、生产交接代码应用真实签名包。
- 实际包集成另 5 组：独立旧版副本升级、217 个以上文件比对、重开、设置/游戏保留、真实 GitHub 检查及退出。文件数以本次包和 QA 报告为准。

```powershell
node native-launcher/scripts/verify-native-update.cjs
node native-launcher/scripts/verify-update-source.cjs
node native-launcher/scripts/verify-update-download.cjs
node native-launcher/scripts/verify-update-security.cjs
node native-launcher/scripts/verify-update-integration.cjs --baseline <旧版完整程序目录>
npm audit --omit=dev
```

测试使用独立 `.qa` 目录；本机原始记录入口为 `.qa/update-security-result.json` 和 `.qa/update-integration-result.json`。安全脚本中的交接测试单独编译与产品相同的 C# 更新代码，绑定产品公钥和实际助手指纹，使用本地真实签名包，不使用发布私钥。镜像故障为受控模拟；GitHub 检查使用真实网络。新版仍未公开，因此不把本地交接说成已完成未来公开版本的线上升级测试。
