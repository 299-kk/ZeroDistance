# ZeroDistance 0.2.1 Preview

本次修复资源筛选浮层、本地资源菜单层级，并将离线联机引导改为当前游戏版本的验证设置。

| 项目 | 变化 |
| --- | --- |
| 资源筛选 | Minecraft 版本选项独立挂载到页面顶层，使用实色背景，避免卡片遮罩和模糊层遮挡；支持点击选项、方向键、Esc、外部点击和外部滚动。 |
| 局域网验证 | “我的游戏 → 版本更多菜单 → 局域网验证设置”提供一键关闭与恢复默认。只在下次启动所选游戏时加载内置补丁，无需额外的联机 MOD，不修改游戏 JAR。 |
| 离线提示 | 不再推荐停更模组，改为说明房主的验证设置，并可直接打开当前实例的版本设置。保留“不再提示”，关闭提示后页面仍有设置入口。 |
| 本地资源 | 父菜单和九个子菜单均为 13px；使用缩进、连接线和分组背景显示层级，展开时不缩小文字。侧栏宽度 132px，可完整显示名称。 |

房主修改设置后应退出并重新启动对应游戏，再将单人世界开放给局域网。该开关不改变他人服务器或独立服务端的验证配置；独立服务端仍由房主设置 `server.properties`。关闭验证后无法核实玩家身份，请仅邀请可信好友，切换前备份存档。

旧版本通过官方方法映射解析目标，无法识别时拒绝启用并显示错误。中文名称的实例使用其实际 Minecraft 版本元数据，不把文件夹名称当作游戏版本号。

## 验证

- 82 项核心与回归测试、5 项启动测试通过，TypeScript 与许可检查通过。
- 正式打包程序通过 5 组新增桌面验证：菜单字号和完整名称、浮层命中与键盘交互、提示偏好、真实设置持久化和恢复、不兼容实例拒绝启用。包含中文实例名；其他实例与游戏 JAR 的 SHA256 保持不变。
- 游戏库、运行进程计数、目录、离线皮肤、后台前置、版本分组、背景和更新记录的桌面回归通过。
- JVM 启用完整字节码验证；使用本机 26.3 的真实 `IntegratedServer` 与 `DedicatedServer` 对象检查：未启用时均返回 true，启用后前者返回 false、后者仍为 true。未创建世界、开放端口或运行游戏 GUI；测试不代表完成两台设备的联机验收。
- 核对 1.20.1 的 Mojang 官方映射及 Fabric intermediary、Forge MCP 映射，并用已有客户端验证目标方法。未逐一运行所有加载器与整合包。
- 最终 ZIP 解压后的 6 组首次声明检查通过；正式用户的同意记录、账号和设置保持不变。已有安装或快捷方式受到保护，本次跳过覆盖安装与卸载测试。
- 正式程序通过版本清单、模组与整合包搜索、Java 检测和离线皮肤模组文件接口检查。四张照片与随包 Java agent 的散列检查通过。

微软账号最终授权、完整游戏内离线皮肤和跨设备联机仍需实际环境验收；本版本继续标为 Preview。
