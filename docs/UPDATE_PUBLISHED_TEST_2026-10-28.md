# 0.3.2 发布后更新测试

2026-10-28，在 Windows 上针对 [0.3.2 Preview](https://github.com/299-kk/ZeroDistance/releases/tag/v0.3.2) 进行隔离测试。发布标签指向提交 `466828d76fbac925e792c3086d342e6a54db6515`。

## 结果

- 隔离的 0.3.1 测试构建在启用自动更新后，使用正式更新代码发现并从公开发布源下载 0.3.2；全程没有更新提示。下载及验证耗时约 31 秒，文件为 39,115,761 字节。
- 测试使用实际发布元数据和文件，没有替换网络响应或发布公钥；校验了固定的发布者 RSA 签名、文件大小和 SHA-256。测试环境检测到了 Windows 系统代理。
- 测试调用正式更新引导程序和助手，在隔离目录静默替换程序；发布 ZIP 内 217 个文件均与更新后的文件逐一匹配。测试存档、主题、内存设置和游戏目录保留，更新后程序正常显示 0.3.2 并启动。
- 测试未修改用户正式安装和数据。由于 QA 模式有意跳过退出时自动交接，这一步由隔离测试程序直接调用正式引导程序验证；该测试没有覆盖正式程序退出事件触发交接的全过程。

公开的旧版 0.3.1 不包含新更新器；本次使用的是版本号设为 0.3.1、但包含 0.3.2 更新器的隔离测试构建。因此，已安装公开 0.3.1 的用户首次升级到 0.3.2 仍需手动安装或替换；这次结果也不能替代将来真实 0.3.2 到后续版本的升级验证。
