ZeroDistance 0.3.7 · 预览版

预览测试开始日期：2026 年 10 月 22 日。
更新历史和测试说明见 CHANGELOG.md、RESULT.md，或启动台右上角“更新日志”。

请完整解压 ZIP 后运行 ZeroDistance.exe；不要只复制 EXE。
需要 Windows x64、.NET Framework 4.8、Microsoft Edge WebView2 Runtime；Java 和游戏按需下载。

本版本保留原有界面、主题和启动动画。内置四张 AI 生成的方块世界背景，可继续导入自定义图片。
默认主题为 0.1.4 青柠。设置 → 外观可关闭启动动画，下次启动生效。
安装时默认创建桌面快捷方式，可在组件选择页取消。

0.3.7 新增模组安装清单：批量检查已声明的依赖、版本和冲突，确认后一次安装。
整合包导入时单个文件断连不再中止整批下载，失败文件会等待后重试，已完成并校验的文件保留。
Minecraft 资源使用 BMCLAPI；CurseForge 与 Modrinth 文件优先尝试 MCIM 国内缓存，未缓存或不可用时回退官方 CDN。
Modrinth 保留 cdn.modrinth.com 与 cdn-raw.modrinth.com 两个入口；cdn-alt 无法解析时自动改回。
设置 → 下载 → 下载镜像可切换“国内镜像优先”和“官方源”，两者都会校验文件大小和哈希。
本版还修复了实例图标占用导致删除失败、旧版 Forge 跨目录启动缺少运行库、NeoForge 安装器不遵循系统代理等问题。

C# 接管桌面窗口与系统能力；启动、下载和联机暂由随包提供的 Node.js 兼容引擎运行。
这不是已经完成全部后端移植的纯 C# 版本。

配置保存在 %APPDATA%\ZeroDistance-Native。
卸载会清除此版本账号、设置、日志、缓存和临时文件，并清理快捷方式及安装注册表。Minecraft 游戏目录和存档保留。
旧安装需先用本版安装程序覆盖更新，才能使用新的卸载清理流程。
不会覆盖 0.2.2 的账号和配置；已有游戏目录仍可发现或手动登记。
使用声明需在前台阅读三秒后同意。

设置 → 行为与登录 → 低占用模式，可手动进入或选择游戏启动后自动进入（默认关闭）。
自动进入时，所有游戏退出后恢复主界面；手动进入时仍由用户手动恢复。
低占用释放 WebView2，已有联机核心和游戏继续运行；无活动核心时业务后端休眠。
下载、安装和未保存编辑会暂缓切换；双击托盘图标恢复完整界面。
正常完整界面未达到 100 MB；真实联机组合的内存因组件而异。

签名更新优先 GitHub，失败后使用配置的镜像；下载完成后正常退出即静默应用，下次打开生效。
0.3.1 及更早版本需先手动安装 0.3.2 或更新版本一次，不能套用旧 Electron 更新包。
