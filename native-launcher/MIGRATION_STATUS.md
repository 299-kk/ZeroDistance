# 架构状态：0.3.3

本阶段将完整桌面界面迁移到 C# + WebView2，并保留原版业务后端。之前的 M1 只验证部分页面和 Java 测试程序，本阶段使用完整的生产页面和真实启动、下载、联机代码。

| 模块 | 当前实现 |
| --- | --- |
| 页面、主题、皮肤编辑器、弹窗、导航 | 原 Vue / CSS / Three.js 源码直接构建 |
| 全屏透明启动动画、高清图标、聚拢及淡入 | 原 C# StartupFeedback 场景，启用快速聚拢及无固定停留 |
| 桌面窗口、边框缩放、窗口按钮、DWM 材质 | C# + Windows DWM + WebView2 |
| 三秒使用声明、前台计时、同意记录 | C#，在功能后端启动前执行 |
| 文件选择、拖入路径、回收站、目录打开、原生菜单 | C# |
| 凭据加解密、PNG/JPEG/位图处理 | C# + Windows DPAPI / System.Drawing |
| 游戏目录、Java、正版/离线账号、皮肤存储 | 原业务模块通过兼容桥运行 |
| Minecraft / 加载器 / 整合包 / 社区资源安装 | 原下载与安装后端通过兼容桥运行 |
| 真实游戏启动、日志、多开状态、实例设置 | 原业务模块通过兼容桥运行 |
| FRP、VoxLink、陶瓦、局域网验证代理 | 原联机和代理协议保留 |
| 安装与 ZIP | 独立原生包，保留原版安装与数据 |
| 卸载清理 | C# 清理本版本软件数据及程序文件；NSIS 移除快捷方式和 32/64 位注册表信息，游戏与存档保留 |

0.3.2 新增 WebView2 释放与重建的低占用模式、GitHub 签名更新及镜像回退。剩余工作包括兼容后端逐步改写，以及完整的多机联机与正版授权回归。系统代理/PAC 行为、高 DPI 和多显示器窗口材质还需要在更多环境对照检查。详见 [内存报告](../docs/MEMORY_2026-10-27.md) 和 [更新流程](../docs/NATIVE_UPDATES.md)。

测试结果见 `RESULT.md`。单机 TCP 转发测试不能替代公网穿透或两个实际玩家的联机测试；取得 Microsoft 设备码不能替代真人完成正版授权。

本地静态页面通过 WebView2 的虚拟主机目录映射读取，使用保留的 `.test` 域名，不使用 HTTP 服务器；已授权图片与插件继续走独立的 WebResourceRequested 通道。桥接只接受本应用页面来源，渲染器不能直接调用内部资源授权通道。首次升级仅为读取旧版界面偏好临时访问旧地址；旧地址不能调用功能桥，迁移后不再使用。相关 API 的行为参考 [Microsoft WebView2 本地内容文档](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/working-with-local-content)。
