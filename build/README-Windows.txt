ZeroDistance 0.3.2 · Windows x64

ZIP 版：先完整解压，再运行 ZeroDistance.exe。请保留其余文件和文件夹。
安装版：运行 Setup.exe，按向导选择安装目录；通过开始菜单或桌面快捷方式启动。
首次使用需阅读并同意使用声明，按钮显示满 3 秒后才能点击；不同意会退出。
声明、账号、设置和日志默认保存在 %APPDATA%\ZeroDistance。
游戏默认安装至 D:\ZeroDistance\.minecraft，D 盘不可用时使用本机后备目录。
卸载程序保留账号设置、同意记录及游戏文件，不自动删除这些数据。
